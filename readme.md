# Website MI Nurul Yaqin Tampumia

## Nama Mitra
MI Nurul Yaqin Tampumia

## Deskripsi Proyek
Website ini dibuat sebagai media informasi MI Nurul Yaqin Tampumia.
Website menampilkan profil madrasah, visi dan misi, berita,
galeri kegiatan, pengumuman, dan kontak.

## Cara Menjalankan di Lokal

1. Install XAMPP.
2. Jalankan Apache dan MySQL.
3. Simpan folder proyek di C:/xampp/htdocs/.
4. Buat database mi_nurul_yaqin di phpMyAdmin.
5. Import file mi_nurul_yaqin.sql.
6. Buka browser.
7. Masukkan alamat:

http://localhost/mi-nurul-yaqin-tampumia/
